# DevOverflow

## Description
DevOverflow is a comprehensive mobile Q&A platform designed for developers. It combines Stack Overflow-style Q&A functionality with social features, gamification, and AI-powered assistance. The application allows users to ask questions, provide answers, interact socially, and engage in gamified learning experiences.

- Core functionality includes user authentication, question and answer management, voting systems, and content moderation.
- Social features enable users to follow others, build friend networks, and track activity feeds.
- Advanced features incorporate AI assistance for content generation and gamification elements like reputation systems and badges.
- The platform supports multimedia content, real-time notifications, and comprehensive search capabilities.

## Features
- User registration and authentication with email verification
- Password reset functionality
- Profile management with avatars and bios
- Question posting with tags and categories
- Rich text answers with voting system
- Social interactions including following and friending
- Bookmarking system for saving questions
- AI-powered content assistance
- Gamification with reputation and badges
- Real-time notifications
- Search and filtering capabilities
- Admin panel for content management
- Multimedia upload support

## Tech Stack
### Backend
- Node.js with Express framework
- MongoDB database with Mongoose ODM
- JWT for authentication
- Cloudinary for media storage
- Google Generative AI integration
- Nodemailer for email services

### Frontend
- Flutter for cross-platform mobile development
- Dart programming language
- HTTP client for API communication
- Shared preferences for local storage
- Secure storage for sensitive data
- Markdown rendering for rich text

## Prerequisites
- Node.js (version 16 or higher)
- MongoDB database
- Flutter SDK (version 3.8.1 or higher)
- Android Studio or Xcode for mobile development
- Git for version control

## Installation and Run Steps
### Backend Setup
1. Navigate to the backend directory
2. Install dependencies using npm install
3. Create a .env file with required environment variables (MongoDB URI, JWT secret, email credentials, etc.)
4. Start the development server using npm run dev
5. For production, use npm start

### Frontend Setup
1. Navigate to the devoverflow directory
2. Install Flutter dependencies using flutter pub get
3. Ensure Android/iOS emulator or device is connected
4. Run the application using flutter run
5. For building APK, use flutter build apk

### Database Setup
1. Ensure MongoDB is running locally or provide cloud MongoDB URI
2. Run the seed script if available to populate initial data
3. Check database indexes are created properly
